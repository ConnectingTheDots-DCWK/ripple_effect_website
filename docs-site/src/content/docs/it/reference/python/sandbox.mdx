Gli script, gli snippet dei passaggi, la console e `python_eval` girano in un interprete Python ristretto, non in CPython. Questa pagina elenca cosa manca, da dove si possono chiamare le funzioni dell'app e i limiti a cui è soggetto uno script.

## Il rapporto fa fede

I limiti dell'interprete cambiano da una versione all'altra, quindi l'app li verifica invece di documentarli. Il **rapporto sulla sandbox**, dietro il pulsante `i` della console, esegue una serie di piccoli snippet nell'interprete reale e riporta l'esito riga per riga. `python_capabilities` restituisce lo stesso testo a un agente ([Strumenti MCP](/it/reference/mcp-tools/#python_capabilities)).

Dove questa pagina e il rapporto non concordano, ha ragione il rapporto.

### Assenze e limiti noti

Sono le righe a cui il rapporto associa un suggerimento, riportato accanto a ciascuna. Il suggerimento compare quando la verifica di quella riga fallisce; la riga `random` nomina anche le schede Dice roller e Weighted branch, cosa che il suggerimento del rapporto non fa.

| Non supportato o limitato | In alternativa |
| --- | --- |
| `class` | Usa un dict. Un componente o un'entità passa come dict: `component_get("Goblin")["HP"]`, mai `goblin.hp`. |
| `random` | Collega una scheda Random number o Random string. Anche le schede Dice roller e Weighted branch coprono il caso sulla lavagna. |
| `yield` (generatori) | Costruisci e restituisci una lista. |
| `match` | Una catena di `if` / `elif`. |
| Formattazione con `%`, `str.format` | Usa una f-string. |
| `collections` (dove il rapporto dice di no) | Un semplice `dict` copre la maggior parte dei casi. |
| `statistics` (dove il rapporto dice di no) | `sum(xs) / len(xs)`. |
| Rete (`requests`, `urllib`) | Nessuna. La sandbox non ha rete. |
| `open`, il filesystem | Uno script legge la storia tramite le funzioni host, non dal disco. |
| `os` | Importabile, ma le chiamate che toccano un disco non sono collegate. |
| `input` | Un passaggio fa domande al lettore; uno script no. |
| `dir()`, `inspect` | Nessuna. Nulla dentro la sandbox può elencare ciò che la sandbox contiene, ed è per questo che il rapporto pone una domanda alla volta. |

Uno snippet ha la forma di Python, ma non è portabile come Python.

## Funzioni host

Tutto ciò che l'app rende disponibile è una **funzione host**: presente senza `import`, senza alcun modulo da cui importarla. Le righe Funzioni host del rapporto chiedono da dove si può chiamarne una. Le verifiche sono scritte in modo da non cambiare nulla.

| Forma di chiamata | Funziona | Altrimenti |
| --- | --- | --- |
| A livello superiore | sì | |
| Dentro un `def` | sì | |
| Dentro una comprehension | sì | |
| Dentro `map()` o `filter()` | no | Riscrivila come comprehension. |
| Dentro `sorted(key=…)` | no | Costruisci prima, in una comprehension, una lista di coppie `(key, name)`, poi ordina quella. |
| Con argomenti per nome | sì | Ogni argomento opzionale dell'API è solo per nome. |
| Intercettare un rifiuto | sì | Un rifiuto arriva come `RuntimeError`. |

```python
pairs = [(entity_get(n)["HP"], n) for n in entity_names()]
weakest = sorted(pairs)[0][1]
```

Il valore restituito da una funzione host è una copia: `e = entity_get("Mira"); e["HP"] -= 3` viene eseguito e non cambia nulla, e per scrivere uno script usa `entity_set`. Vedi [Le letture sono copie](/it/reference/python/).

## Limiti

| Limite | Valore | Oltre il limite |
| --- | --- | --- |
| Tempo | 2000 ms (due secondi), controllato a ogni istruzione | Lo script viene interrotto con un `Timeout`; la storia prosegue. |
| Memoria | 64 MB, circa | `MemoryError` |
| Profondità di ricorsione | 200 frame | `RecursionError` |
| Script fuori controllo | 3 per sessione di gioco | Vedi sotto. |

Il rapporto segnala ogni limite come applicato.

### Script fuori controllo

Uno script interrotto dal limite di tempo non viene riavviato nella stessa sessione di gioco. La corrispondenza avviene sul sorgente dello script, non sul suo nome: il nome di uno snippet è lo stesso per ogni passaggio, e il sorgente di una scheda Script include i suoi ingressi, quindi la stessa scheda con ingressi diversi è uno script diverso.

Dopo che tre script distinti sono stati interrotti in una sessione di gioco, non parte più nessuno script. Uno script che arriva a questo punto contiene un ciclo infinito.
