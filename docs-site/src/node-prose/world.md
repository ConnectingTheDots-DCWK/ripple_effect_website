What the story reads of the reader's world: where they are and what time it is, each only when the reader allows it. A story with one of these on a board asks before it begins. Each takes the flow and has an `unavailable` way out for a read that got nothing; left unwired, the story carries on by `completed` or `no`. Python reads the same things — see [The world outside the story](/reference/python/the-world/).
