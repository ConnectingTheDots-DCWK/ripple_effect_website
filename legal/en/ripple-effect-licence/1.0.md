**Ripple Effect Licence, version 1.0 (English)**
Superseded. This is the short notice that shipped with Ripple Effect 1.4 and
every build before it, and it governs those builds for as long as they are
used. From Ripple Effect 1.5 the application asks you to accept the
[End-User Licence Agreement](/eula/) instead, and that Agreement governs every
build that asks.

It is published here for one reason: the Agreement that replaced it says a
build earlier than 1.5 remains under this notice, and a notice nobody can read
is not a notice. The text below is the text that shipped, unchanged, save that
the enquiry address at the end has been replaced with the one that is answered
today — the original named a personal mailbox.

This page is frozen. A superseded notice has nothing left to correct, and
anybody still running an older build is entitled to find exactly what they
found when they installed it.
